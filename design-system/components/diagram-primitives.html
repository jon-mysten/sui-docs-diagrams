Diagram primitives

Every primitive a Sui-compliant C4 diagram is built from. Hex values are inlined for portability; CSS-variable equivalents are in ../tokens.css.

Brand palette

Every fill, stroke, and text color in a Sui diagram is drawn from one of three groups: the four-color core, the extended Blue scale (50–900), or the extended Gray scale (50–900). Any color outside these three groups is a compliance failure. Inside them, all are valid; the role table in DESIGN.md §3 describes when to reach for the extended scales.

Pass criteria. Every box below should be true:
  • The Inter rows look noticeably different from Times New Roman or Cambria (Inter has a more neutral, vertical character)
  • The Inter Medium row has visibly heavier strokes than Inter Regular
  • Inter Tight is slightly narrower than Inter at the same weight
  • DM Mono rows are monospaced. Every character takes the same horizontal space
  • The Sui Blue "gRPC" on black at the bottom is clearly readable
If any of those fail, the @font-face declarations in tokens.css are not resolving, typically because this file is opened from a location where the relative path ../assets/fonts/ doesn't point at the right place. Open this file from inside the design-system/ folder of the unzipped package.

transactions.mdx flowchart Anti-example

Source: docs/content/concepts/transactions.mdx · Live page: docs.sui.io/concepts/transactions

Do not pattern-match against this diagram. It predates the current Sui Technical Diagram Standards and contains compliance failures noted below. The compliant rewrite on the right is what new diagrams should look like.

Original (non-compliant)

Why it fails:

  • Off-palette fills: #f225 (red 22% alpha) and #ff43 (yellow 27% alpha) are 4-digit ARGB hex, not on the Sui palette
  • Arrow stroke is gray #888888, not Sui Blue 500 (#298DFF)
  • Ellipses used for objects when they should be filled rectangles for primary nodes
  • Color used as the sole emphasis signal (no Black for primary objects, no Gray 500 for byproducts)
  • Transaction labels not in TX-N casing convention

Compliant rewrite

What changed:

  • Object A → Black (primary), Object B → Gray 500 (byproduct), Object C → Sui Blue 500 (tertiary)
  • All arrows in Sui Blue 500 with filled triangle heads
  • Filled rectangles for primary nodes (not ellipses)
  • ALL CAPS on primary labels, sentence case on sub-labels
  • Transaction labels in TX-N convention, sitting on arrows in Sui Blue
  • Three-tier emphasis hierarchy makes the value path readable at a glance
